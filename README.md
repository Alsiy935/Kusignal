# KuCoinSignalApp PRO v5 RU

Русский интерфейс для KuCoin Futures.

Особенности:
- 5m / 15m / 1h / 4h закрытые свечи
- EMA 20 / 50 / 200
- RSI 14
- MACD
- Wilder ADX
- ATR-based risk levels
- объём
- структура и breakout proximity
- дисбаланс стакана
- изменение OI примерно за 30 минут
- funding
- отдельные LONG / SHORT scores
- вход разрешается только при согласовании тренда 4Ч + 1Ч
- при отсутствии согласования приложение явно показывает «ОЖИДАНИЕ»
- цены отображаются без длинных хвостов из нулей

Приложение использует только публичные рыночные данные и не размещает ордера.
