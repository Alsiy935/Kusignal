# Futures Signal Android App

Android app for KuCoin Futures public market data. It analyzes LONG/SHORT/WAIT and shows Entry, SL, TP1, TP2, TP3.

## Build without a PC
Upload this project to GitHub from a phone, then open **Actions → Build APK → Run workflow**. The APK appears under the workflow run's Artifacts.

The app uses KuCoin UTA V2 public Kline API and does not need an API key for market-data analysis.
