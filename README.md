# KuCoinSignalApp PRO v6 RU

Усиленная версия сигнального сканера KuCoin Futures.

Что добавлено:
- подтверждение направления на 1D + 4H + 1H + 15m + 5m;
- EMA 20/50/200, RSI, MACD;
- Wilder ADX + +DI/-DI;
- VWAP и Bollinger Bands;
- объём и структура рынка;
- стакан, OI и funding;
- Mark Price / Index Price;
- проверка близости противоположного уровня;
- режим «ОЖИДАНИЕ», если критические фильтры не подтверждены;
- простая историческая проверка устойчивости режима на 1H без использования будущих свечей;
- повтор запросов API при временной ошибке;
- вход блокируется, если критические рыночные данные не получены.

Оценка 0–100 — это оценка подтверждения условий, а не вероятность и не гарантия результата. Приложение использует только публичные рыночные данные и не размещает ордера.
