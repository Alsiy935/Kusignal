# V13 UI redesign

The Android UI was redesigned to follow the approved dark trading-app layout:

- fixed top header with hamburger, title/subtitle, fullscreen and menu controls;
- large searchable coin field and filter chips;
- scrollable coin cards with touch-safe hit areas;
- fixed-size progress/status card area inside the scroll content;
- prominent blue Stop button;
- collapsible recent-events log;
- fixed bottom navigation for Scanner / Analysis / Model / Settings;
- responsive portrait/landscape calculator layout;
- no horizontal scrolling in the main screen;
- top controls remain above the ScrollView so they receive touch events.

Trading, scanner, prediction, calculator and learning logic are preserved from V13.
