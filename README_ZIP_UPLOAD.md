# Загрузка одним ZIP — как в предыдущем проекте

1. Загрузи ZIP этого проекта в корень GitHub repository.
2. Открой Actions.
3. Запусти `Install project ZIP`.
4. Workflow сам распакует ZIP и разложит проект в корне.
5. После этого появится обычный workflow сборки APK.
6. Запусти `Build Android APK`.
